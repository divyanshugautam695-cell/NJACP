- [x] Manual task creation
- [x] Completion tracking
- [x] Local persistence in the browser
- [x] AI-assisted planning with deterministic fallback
- [x] Recovery-oriented messaging
- [x] Demo documentation

## Why local persistence?

The study queue is saved in the browser so a student can leave the page and return without losing the current plan. No account or database is required for this feature.

## Suggested judging demo

Start with the default queue, set low energy and a short available-time window, and adapt the plan. Then mark a task complete, change the available time, and adapt again to demonstrate that the planner responds to changing circumstances.
